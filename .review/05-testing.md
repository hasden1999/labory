## 🔍 الملاحظات التفصيلية بالأدلة البرمجية

### [TEST-001] غياب أمر الاختبار القياسي `npm test` في ملف `package.json` 🟠 عالٍ (High)
- **الموقع:** `package.json:8-30`
- **المشكلة:**
  يحتوي ملف `package.json` على أوامر البناء والتشغيل (`build`, `dev`, `desktop`, `release`) لكنه يفتقر تماماً لأمر `test`:
  ```json
  "scripts": {
    "build": "npx prisma generate ...",
    "dev": "concurrently ...",
    "test:devices": "python tests/integration/test_astm_analyzer.py"
    // Missing: "test": "tsx tests/e2e/run_all.ts"
  }
  ```
- **الأثر:**
  فشل أي خط أنابيب CI/CD تلقائي (مثل GitHub Actions) أو أي فحص ما قبل الرفع (Pre-push hook)، وظهور رسالة الخطأ `npm ERR! Missing script: "test"`.
- **الحل المقترح:**
  إضافة `"test": "npx tsx tests/e2e/run_all.ts"` في `package.json`.
- **الجهد:** صغير (Small).

---

### [TEST-002] انعدام اختبارات الوحدات لمكونات الواجهة السريرية (Missing Component Unit Tests) 🟡 متوسط (Medium)
- **الموقع:** `apps/web/src/components/workstations/` و `apps/web/src/components/UrineFormModal.tsx`
- **المشكلة:**
  لا توجد أي ملفات اختبار لوحدات الـ React (`Jest`, `Vitest`, أو `React Testing Library`). كل الاختبارات الموجودة حالياً تركز على منطق الـ Backend والـ Calculations ولا تفحص تفاعل الفني مع الواجهة (UI Events، النقر على الأزرار السريعة، إدخال الأرقام بالنومباد).
- **الأثر:**
  خطر حدوث أخطاء ارتدادية (Regressions) عند تعديل أي استمارة سريرية (مثل التعديلات الأخيرة على FOBT وحساسية الخروج وكريات الدم البيض) دون وجود درع اختبارات واجهة تلقائي.
- **الحل المقترح:**
  تثبيت `Vitest` مع `@testing-library/react` وكتابة اختبارات تفاعلية لاستمارات التحاليل التخصصية.
- **الجهد:** متوسط (Medium).

- **المشكلة:**

- **الأثر:**
