## 1. نبذة عن المشروع ونوعه (Project Classification)
- **اسم المشروع:** Labryo LIMS (`lab-manager-monorepo`)
- **الإصدار الحالي:** v2.1.1 (إنتاج رسمي ومحدث)
- **طبيعة النظام:** نظام متكامل لإدارة المختبرات الطبية والتحليلات السريرية (Laboratory Information Management System - LIMS).
- **النمط المعماري الأساسي:** Monorepo (باستخدام npm workspaces) يدمج بين:
  1. تطبيق سطح مكتب مدمج (Desktop Electron App) يعمل بنمط محلي بالكامل دون اتصال بالإنترنت (Offline-First / On-Premise).
  2. واجهة ويب حديثة سريعة بنظام Next.js 14.2 (App Router) وفق معمارية Feature-Sliced Design (FSD).
  3. خادم خلفي عالي الأداء معتمد على Fastify 4 مع Prisma ORM وقاعدة بيانات SQLite بنمط الذاكرة والمزامنة WAL.
  4. محرك مدمج للتكامل مع الأجهزة الطبية والمحللات الآلية (ASTM E1381/E1394 و HL7 على المنفذ 5000).
  5. بوابة تراسل طبي مؤتمتة عبر WhatsApp Web (Baileys v6).

## 5. بيئة التشغيل والتوزيع والتوافق (Runtime & Target Deployment)
- **النظام المستهدف:** أنظمة Windows (سطح المكتب، بيئة محلية Offline-First وشبكة داخلية LAN).
- **التوافقية العتادية الشاملة:**
  - نسخة حديثة x64 (Electron 30 + Node 20) لأنظمة Windows 10/11.
  - نسخة موسعة Legacy x86 (Electron 22 + Node 18.20.7 ترقيع PE لـ advapi32) لأنظمة Windows 7 SP1 إلى Windows 8.1 مع سقف ذاكرة 768MB.
- **التثبيت والتحديث:** مثبت مستقل بنظام NSIS بحجم ~107 ميجابايت (`Setup.exe`) مع آلية تحديث تلقائي آمنة عبر قنوات GitHub Releases الموثقة (`stable.yml`, `latest.yml`, `legacy.yml`).
- **منظومة الأمان والترخيص الحالية:**
  - ترخيص Ed25519 رقمي غير متماثل (`LIC2-`) مع مفتاح عام مشفر.
  - ختم بصمة الجهاز العتادية السريعة (`HMAC-SHA256 HWID Seal`) بزمن تحقق فائق 0.15ms.
  - حماية نقاط النسخ الاحتياطي بفحص Loopback محلي وتوكن إداري صارم.
