# تكليف وكيل ضمان الجودة المستقل (AGENT_BRIEFS/QA.md)

## الهدف (Goal)
امتلاك حزمة الاختبارات الذهبية (Golden Tests)، اختبارات الحدود (Boundary Tests)، ومدقق النطاق المعماري (`npm run check:scope`)، وتشغيل الفحوصات بعد كل عملية دمج، مع التمتع بسلطة الفيتو (Veto Power) لرفض أي دمج يكسر أي ميزة أو يُحدث تراجعاً في السلوك. في النهاية، إجراء تدقيق شامل للأعين المستقلة مقابل `FEATURE_INVENTORY.md`.

## المجلدات المملوكة (Owned Dirs)
- `tests/`
- `tests/golden/`
- `tools/check_scope.js`
- `tools/lint_boundaries.js`

## المسارات المحظورة (Forbidden Dirs)
- كود المنتج في `apps/` و `packages/` (باستثناء أدوات الاختبار).

## الخطوات التنفيذية (Steps)
1. تشغيل `npm run lint:boundaries` للتأكد من احترام طبقات النظام.
2. تشغيل `npm run test:golden` بعد كل مرحلة دمج.
3. التحقق من ثبات عدد الكتالوج وسلامة تصيير الـ PDF باللغة العربية (RTL).
4. التحقق من خلو العمليات من أي أخطاء أو كسر للواجهات.

## معايير القبول (Acceptance Criteria)
- [ ] نجاح 5/5 من الاختبارات الذهبية بنسبة 100%.
- [ ] اجتياز مدقق النطاق `check:scope` للطبقة المدمجة.
- [ ] اجتياز `npm run build` بنجاح دون أي خطأ في التحزيم.

## صيغة التسليم (Handoff Format)
توليد تقرير `HANDOFF_QA.md` يتضمن نتائج الاختبارات وأي ملاحظات أو فيتو معلن.
