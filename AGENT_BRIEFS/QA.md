# AGENT BRIEF: QA (Agent D)

## الهدف (Goal)
حارس الجودة وضمان عدم الانحدار (`Quality Assurance & Regression Prevention`). وكيل مستقل لا يكتب أي كود للمنتج.

## المهام الأساسية (Responsibilities)
1. **فحص نطاق التعديل (`Diff Scope Check`)**:
   - التحقق من أن ناتج `git diff --name-only` هو مجموعة جزئية دقيقة من الملفات الجديدة المنشأة بالإضافة إلى قائمة `TOUCH_POINTS.md`.
   - أي ملف خارج القائمة يرفض الدمج فوراً ويتطلب مبرراً خطياً في `SCOPE_EXCEPTIONS.md`.
2. **الاختبارات الذهبية (`Golden Regression Gate`)**:
   - تشغيل حزمة الاختبارات الذهبية `npm run test:golden` بعد كل مرحلة ودمج.
   - التأكد من تطابق المخرجات 100% مع الوضع الأساسي عندما تكون الخيارات الجديدة غير مفعلة (Off/Null).
3. **تدقيق الاستقرار والأنواع**:
   - تشغيل `npm run typecheck` و `npm run build`.
   - تدقيق عيني على ملفات الـ PDF وسلوك الشاشات عند تفعيل الخيارات الجديدة.
