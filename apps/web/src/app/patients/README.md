# وحدة إدارة المرضى (Patients Module)

## الغرض الوظيفي (Purpose)
إدارة بيانات المرضى وسجلاتهم الطبية، بما في ذلك البحث الفوري بالاسم أو رقم الهاتف، إضافة مريض جديد، تعديل البيانات الديموغرافية (العمر، الجنس، العنوان، الملاحظات السريرية)، واستعراض السجل التاريخي لكافة عينات وفحوصات المريض.

## واجهات البرمجة والمسارات (Public API)
- `GET /api/patients`: جلب قائمة المرضى مع دعم التصفح والتصفية.
- `GET /api/patients/search?q=`: بحث فوري بالاسم أو رقم الهاتف.
- `GET /api/patients/:id`: جلب الملف الطبي المفصل للمريض مع تاريخ العينات.
- `POST /api/patients`: تسجيل مريض جديد في النظام.
- `PATCH /api/patients/:id`: تحديث بيانات المريض.

## الملفات الأساسية (Key Files)
- `page.tsx`: الشاشة الرئيسية لإدارة وسجلات المرضى.
- `../../components/patients/PatientFormModal.tsx`: استمارة إضافة وتعديل المريض.
- `../../lib/api.ts`: استدعاءات API الخاصة بوحدة المرضى.
