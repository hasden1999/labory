# وحدة إعدادات النظام والهوية (Settings Module)

## الغرض الوظيفي (Purpose)
إدارة الهوية المؤسسية للمختبر (الاسم العربي والإنجليزي، الشعار، العناوين، وأرقام الهواتف)، تخصيص ترويسة وتذييل تقارير الطباعة، إعدادات خادم ومحرك التقارير، النسخ الاحتياطي اليدوي والتلقائي لقاعدة البيانات، ربط وتفويض محرك الواتساب، والتحكم في إعدادات قنوات التحديث الآلي.

## واجهات البرمجة والمسارات (Public API)
- `GET /api/settings`: جلب الإعدادات المركزية للمختبر.
- `POST /api/settings`: حفظ وتحديث إعدادات المختبر والطباعة.
- `GET /api/backup/export`: إنشاء وتصدير نسخة احتياطية مشفرة من قاعدة البيانات.
- `POST /api/backup/restore`: استعادة نسخة احتياطية مع تأكيد الأمان.
- `GET /api/version/check`: التحقق من توفر تحديثات جديدة للنظام.

## الملفات الأساسية (Key Files)
- `page.tsx`: الشاشة الشاملة للتبويبات (الهوية، الطباعة، النسخ الاحتياطي، المزامنة، التحديثات).
- `../../lib/serverStore.ts`: التخزين المركزي الموثوق للإعدادات.
- `../../components/SettingsModal.tsx`: النوافذ الإضافية لإعدادات الطابعات والباركود.
