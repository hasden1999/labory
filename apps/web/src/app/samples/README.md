# وحدة تسجيل واستقبال العينات (Accession & Samples Module)

## الغرض الوظيفي (Purpose)
استقبال المرضى وتسجيل طلبات الفحوصات الطبية، إنشاء أرقام العينات التسلسلية اليومية والسنوية، اختيار باقات التحاليل أو الفحوصات الفردية، تحديد الطبيب المحيل، إصدار الفواتير وتحصيل الدفعات (نقداً أو ديناً أو خصماً)، وطباعة باركودات العينات للأنبوب المخبري فورياً.

## واجهات البرمجة والمسارات (Public API)
- `GET /api/samples`: جلب قائمة العينات مع فلاتر الحالة والتاريخ والطبيب.
- `POST /api/samples`: إنشاء عينة جديدة مع الفحوصات المطلوبة وربطها بالمريض.
- `GET /api/samples/:id`: جلب تفاصيل العينة الكاملة.
- `GET /api/samples/:id/barcode`: توليد وطباعة باركود أنبوب العينة (Code 128).
- `POST /api/samples/:id/pay`: تسجيل وتحديث الدفع المالي للعينة.
- `POST /api/samples/:id/reject`: رفض العينة مع توثيق السبب الطبي (تحلل الدم، تجلط، كمية غير كافية).

## الملفات الأساسية (Key Files)
- `page.tsx`: شاشة استقبال العينات وتسجيل الفحوصات.
- `../../components/samples/AccessionModal.tsx`: استمارة تسجيل العينة واختيار الفحوصات.
- `../../components/workspace/TechnicianCommandCenter.tsx`: لوحة العمل السريع للفنيين.
