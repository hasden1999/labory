# وحدة دليل التحاليل والباقات (Test Catalog & Panels Module)

## الغرض الوظيفي (Purpose)
إدارة كتالوج الفحوصات الطبية المعتمدة في المختبر (144 فحصاً نشطاً)، ضبط الأسعار والتكاليف، تحديد المديات المرجعية الطبيعية والحرجة حسب العمر والجنس ومصادر التوثيق، إدارة باقات التحاليل التشخيصية (Panels)، مع منع التكرار الجذري التلقائي.

## واجهات البرمجة والمسارات (Public API)
- `GET /api/tests`: جلب قائمة التحاليل مع إمكانية البحث والتصفية بحسب التصنيف المخبري.
- `POST /api/tests`: إضافة فحص مخبري جديد (محمي بضوابط منع التكرار 409 Conflict).
- `PATCH /api/tests/:id`: تعديل فحص أو سعره أو مدياته المرجعية.
- `DELETE /api/tests/:id`: حذف أو أرشفة الفحص (فقط عند صفر مراجع تاريخية).
- `GET /api/tests/panels`: استعراض باقات التحاليل والفحوصات المنضوية تحتها.

## الملفات الأساسية (Key Files)
- `page.tsx`: شاشة دليل التحاليل واستعراض الباقات والأسعار.
- `packages/data/src/catalog/catalogData.ts`: التعريفات المعيارية والبيانات المرجعية الأولية للكتالوج.
- `../../lib/catalogCache.ts`: الذاكرة المؤقتة لمزامنة الكتالوج بين التخزين المحلي وقاعدة البيانات.
